# 🧮 Tip Calculator

A simple Python program that calculates the total bill including the tip and splits it equally between multiple people.

## 🚀 Features

* 💰 Enter the total bill
* 💸 Choose a tip percentage
* 👥 Split the bill between multiple people
* 🧮 Calculate the amount each person should pay

## 🛠️ Built With

* 🐍 Python
* `input()`
* Variables
* Arithmetic Operations
* `float()` & `int()`
* `round()`
* f-strings

## 📌 Example

```text
Welcome to the tip calculator!
What was the total bill? $100
What percentage tip would you like to give? 10 12 15 15
How many people to split the bill? 4

Each person should pay: $28.75
```
